專案名稱與介紹
  專案名稱：Our+ | 家庭溫度與學習陪伴平台
  1.這是什麼程式？
    Our+ 是一套專為現代家庭打造的「雙向公約簽署、課業自主打卡與親子心靈願望池」陪伴系統。平台以「平權、信任、溫度」為核心，打破傳統由上而下的命令式管教，提供家長與孩子各自獨立的專屬空間。
  2.能幫人解決什麼問題？
    化解親子衝突與猜疑：透過家長簽署「開明條約」（承諾聆聽不批判）與孩子簽署「誠實條約」（用自律換取信任），建立家庭共同遵守的公約基石。
    解決課業督導的焦慮感：內建臺灣教育部 108 課綱完整架構（涵蓋國小 16 年級及國中 79 年級各科單元），孩子只需自主打卡課後進度與筆記，家長能即時看見孩子的努力，無需緊迫盯人。
    縮減兩代溝通的認知落差：透過雙向心靈默契問卷（涵蓋開明度光譜、學科挑戰認知與願望模式），生成溫暖的「家庭心靈默契卡」，讓父母讀懂孩子默默承受的壓力，孩子也能理解父母笨拙的關懷。
    實踐正向激勵機制：提供「親子願望池」，孩子可提出實質、休閒或情感真心話願望並承諾付出，家長可直接批准或設定學科加碼激勵條件，養成健康自律的生活節奏。
技術說明
  使用的模型：
    模型版本：Gemini 1.5 Pro（亦可相容於 Gemini 1.5 Flash / gemini-2.5 系列高階推理模型）。
    應用情境：用於運算家長端與學生端兩份獨立問卷的深層心理分析，包含教養光譜同頻差距計算、學科信心認知落差比對，並以溫暖同理的口吻生成「家庭心靈默契卡」、「給這家庭的一封暖心信箋」與客製化親職溝通錦囊。
  開發語言與技術架構：
    程式語言：TypeScript (JavaScript 現代強型別超集)
    前端框架：React 19 搭配 Vite 高效能建置工具
    樣式與設計系統：Tailwind CSS（搭配溫暖家庭色系：琥珀黃、珊瑚粉、天藍色）
    圖標與動畫互動：Lucide React 圖示庫、Canvas Confetti（願望達成與打卡彩花特效）
    狀態與儲存架構：以 TypeScript 嚴格定義資料模型（types/index.ts），資料以持久化 LocalStorage 進行即時跨角色雙向同步，支援多裝置模擬與一鍵示範數據重設。
